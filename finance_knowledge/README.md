# 💰 金融投资知识库

## 目录结构

```
finance_knowledge/
├── README.md           # 本文件 - 知识库说明
├── reports/            # 原始投资报告（存放别人写的报告）
├── analysis/           # 报告分析（Lily 对报告的分析和提炼）
├── models/             # 分析模型（学习到的分析框架）
├── strategies/         # 投资策略（总结的投资策略）
└── learned/            # 学习笔记（Lily 的学习心得）
```

## 使用方法

### 📥 存放报告
将别人的投资报告放到 `reports/` 目录下，命名建议：
```
reports/
├── 2026-03-22_XX证券_行业分析.md
├── 2026-03-22_XX基金_投资策略.pdf
└── 2026-03-22_XX机构_宏观研究.md
```

### 📚 学习流程
1. Lily 读取报告内容
2. 分析报告的分析框架和方法
3. 提炼关键观点和逻辑
4. 更新 `analysis/` 目录下的分析笔记
5. 总结到 `models/` 和 `strategies/`

### 📁 文件格式

#### analysis/YYYY-MM-DD_报告标题_分析.md
```markdown
# 报告分析：[标题]

## 原报告信息
- 来源：
- 日期：
- 类型：

## 分析框架
[作者使用的分析方法]

## 核心观点
[主要结论]

## 逻辑链条
[推理过程]

## 值得学习的地方
[分析技巧、数据来源、表达方式等]

## 可复用的模型
[可以借鉴到其他分析中的方法]
```

#### models/分析模型名称.md
```markdown
# [模型名称]

## 适用场景
[什么时候用这个模型]

## 核心指标
[需要关注的数据]

## 分析步骤
[具体操作流程]

## 判断标准
[如何解读结果]

## 来源
[学习自哪份报告]
```

#### strategies/策略名称.md
```markdown
# [策略名称]

## 策略逻辑
[为什么这个策略有效]

## 触发条件
[什么时候执行]

## 操作步骤
[具体怎么做]

## 风险控制
[如何止损]

## 回测结果
[历史表现]
```

## 知识库维护

Lily 会在以下时机更新知识库：
1. 收到新报告时 - 分析并提炼
2. 定期回顾时 - 更新模型和策略
3. 市场变化时 - 补充新的认知
