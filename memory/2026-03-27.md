## 飞书消息无响应问题
- **现象：** 飞书发消息没反应，Gateway 状态显示 Feishu "ON / OK" 但实际不工作
- **原因：** Windows 休眠导致 WSL2 网络栈重置，飞书 WebSocket 长连接断开，Gateway 不一定能自动重连
- **解决：** 手动 `openclaw gateway restart` 即可恢复
- **备注：** Gateway 进程本身不会被休眠杀死，是网络连接层面的问题

## WSL2 网络保活
- 问题：Windows 休眠 → WSL2 网络断开 → "Network connection lost"
- 解决方案：
  - `scripts/wsl-network-keepalive.sh` — 每 30 秒 ping 网关
  - cron 每 5 分钟检查脚本存活，挂了自动重启
  - 创建 Windows `.wslconfig` 开启 mirrored 网络模式（需重启 WSL 生效）
- 重启 WSL 后生效：`wsl --shutdown` 再重新打开
