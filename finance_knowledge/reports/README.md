# 📥 投资报告存放目录

## 如何使用

将别人写的投资报告放到这个目录下。

### 支持的格式
- `.md` - Markdown 格式（推荐）
- `.txt` - 纯文本格式
- `.pdf` - PDF 格式（需要额外处理）

### 命名建议
```
YYYY-MM-DD_来源_标题.md

例如：
2026-03-22_中信证券_新能源行业分析.md
2026-03-22_高盛_2026年宏观展望.md
2026-03-22_某基金经理_投资心得.md
```

## 分析报告

Lily 会自动分析你上传的报告，提取：
- 📊 关键指标（PE、PB、ROE等）
- 🏭 涉及行业
- 💡 核心观点
- 🔗 逻辑链条
- 💰 投资建议

分析结果保存在 `../analysis/` 目录。

## 学习笔记

Lily 会把学习心得记录在 `../learned/` 目录，包括：
- 分析框架学习
- 数据来源整理
- 可复用的方法
- 待深入研究的问题
