## 关键教训
- Docker 构建缓存问题在低带宽服务器上特别顽固
- Vite 的 tree-shaking 可能产生意外结果，需要检查产物而不仅看源码
- WSL2 中 SSH 到远程服务器时，sudo + heredoc 的嵌套引号容易出问题
- sftp 上传文件比 heredoc 可靠得多
- 阿里云 ECS 需要配置安全组开放端口（仅防火墙不够）
